# Spectrum Bench

A playable optics bench: light sources, prisms, lenses, flat and curved mirrors, diffraction gratings, color filters, beam splitters, slits and screens.

Open `index.html` from a web host (such as GitHub Pages) in Safari, then use **Share → Add to Home Screen** with **Open as Web App** on. After the first visit it works offline.

To update, replace `index.html` with the new version. The page refreshes itself the next time you open it online.

## Resonant Ink

`resonant-ink.html` is a separate page in the same folder: a multi-touch fluid simulation. Stir the dye with as many fingers as you like, and tune vorticity, viscosity, dye density, fade and diffusion. Colors, bloom and a kaleidoscope mirror are adjustable. Audio-reactive spots fire from a frequency band you pick on the live spectrum, with an adjustable sensitivity. The sound can come from the built-in demo beat, a song file, or the microphone.

Open it at `resonant-ink.html` next to `index.html` on the same host. The microphone needs a secure (https) host such as GitHub Pages and your permission. Songs play locally and are never uploaded. Settings are remembered in the browser, and the page works offline after the first visit, like the bench.
