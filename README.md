# Spectrum Bench

A playable optics bench: light sources, prisms, lenses, flat and curved mirrors, diffraction gratings, color filters, beam splitters, slits and screens.

Open `index.html` from a web host (such as GitHub Pages) in Safari, then use **Share → Add to Home Screen** with **Open as Web App** on. After the first visit it works offline.

To update, replace `index.html` with the new version. The page refreshes itself the next time you open it online.
