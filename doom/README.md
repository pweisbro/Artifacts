# DOOM engine files

These files run `doom.html`.

- `websockets-doom.js` and `websockets-doom.wasm`: Chocolate Doom compiled to WebAssembly with Emscripten and SDL2, from Cloudflare's doom-wasm project. Source: https://github.com/cloudflare/doom-wasm (based on https://github.com/chocolate-doom/chocolate-doom, itself based on id Software's 1997 DOOM source release). Licensed under the GNU General Public License, version 2; the full text is in `COPYING`. This copy came from the npm package `@nicejsisverycool/tizendoom` 0.1.6, which republishes that build; its version banner reads "Websockets Doom 0.0.1".
- `doom1.wad`: the DOOM shareware WAD, version 1.9 (MD5 `f0cefca49926d00903cf57551d901abe`). DOOM is © id Software. The shareware episode may be shared freely as long as it isn't changed or sold.

No retail WADs are stored here. Players add their own in the page; those stay in their browser.
