Game data

    The shareware episode, Knee-Deep in the Dead, is built in. If you own DOOM, DOOM II, Final DOOM or The Ultimate DOOM, add its .wad file (for example DOOM.WAD or DOOM2.WAD from the game's folder on Steam or GOG). It stays on this device, saved in this browser only, and is never uploaded. Free Freedoom WADs work too.
