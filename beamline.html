Getting it onto the FB4

  1. Open the files in BEYOND or QuickShow on the computer connected to the FB4. BEYOND loads ILDA (.ild) files straight into its frame editor and cue grid.
  2. Set the playback speed to the same frames per second as above, so the loops run at the right tempo.
  3. Line the cues up with the song on the software's timeline, using the cue sheet.
  4. To run without a computer, use the software's FB4 Export to copy the show onto the FB4's SD card.

Laser light can hurt eyes. Keep beams well above people's heads unless the setup is made and approved for audience scanning, and test new looks at low power.
